# StudyTrace 复赛呈现与验收清单

> 目标：用 2-3 分钟讲清楚 StudyTrace 的真实学习价值，而不是展示功能清单。

## 2-3 分钟黄金路径

1. **进入学习路径**
   使用体验账号或本机体验进入 App，先停在首页。重点说清楚：StudyTrace 打开后先告诉学生“今天先做哪一步”。

2. **展示真实学习材料**
   使用高数极限/洛必达错题主线。说明学生不是从空白页开始，而是从近期学习记录、任务、闪卡和笔记继续接上。

3. **让学习助手整理下一步**
   在学习助手输入类似内容：
   `今天做高数极限题，洛必达适用条件还不熟，帮我整理下一步、闪卡和笔记。`

4. **展示整理结果落地**
   重点看四个落点：任务清单、学习笔记、知识闪卡、学迹回看。讲法建议：AI 不只是回答，它把学习材料变成明天能继续执行的安排。

5. **回到学迹回看**
   展示学迹页的摘要、下一步和学习整理来源。收束到一句话：学生能回看“自己为什么这样学、下一步该做什么”。

## vivo AIGC 能力到学习价值

| 能力方向 | StudyTrace 落点 | 用户价值 |
| --- | --- | --- |
| 大模型文本理解与结构化生成 | 学习整理、任务草稿、笔记草稿、闪卡生成 | 把零散材料变成可执行学习路径 |
| 多轮对话与工具调用 | 学习助手对话、保存任务、保存笔记、生成闪卡 | 不停留在聊天，直接沉淀到 App 内 |
| 图片理解与 OCR | 拍题整理、课堂图片转笔记 | 学生可以从题目、板书、截图开始复盘 |
| 图片生成 | 学习图解、流程图、知识点配图 | 把抽象概念变成更容易回看的视觉材料 |
| 视频生成 | 回顾短片 | 把阶段学习内容转成轻量回顾材料 |
| 语音转写 | 语音复盘、专注后记录 | 降低记录门槛，适合移动端碎片场景 |
| 语义检索与记忆 | 找回任务、日志、笔记、闪卡 | 学生可以接着过去的难点继续学 |
| 本机可用 + 资料备份 | 本地记录、登录后备份 | 网络不稳定时不阻断学习路径 |

## 验收清单

- 首页第一屏能在 10 秒内讲清“今天先做什么”。
- 体验账号进入后不是空壳，能看到学习记录、任务、闪卡、笔记和学迹。
- 学习助手回复先给下一步，不把技术字段展示给用户。
- 整理结果能落到至少一个真实对象：任务、笔记、闪卡或学迹。
- 失败态不出现 HTTP、服务器、后端、targetId、status、提示词等出戏词。
- 图解/短片生成失败时有温和兜底，不承诺已经生成。
- 本机体验可用，登录后资料备份口径不过度承诺多端实时同步。
- 录屏时优先走高数/洛必达主线，避免临时跳到无关页面。

## 推荐收尾话术

StudyTrace 的核心不是“AI 会聊天”，而是让大学生把每天零散的学习材料整理成能继续执行、能复习、能回看的学习路径。它把模型能力藏在真实学习动作后面：记录难点、整理下一步、生成闪卡、沉淀学迹，最后让学生第二天还能接着学。
